Only searchable pull requests in currently owned public MicrosoftDocs repositories are included. Private, deleted, hidden or transferred-out history cannot be reconstructed. GitHub’s search indexing can lag.

Retrieval uses a fixed creation-time cutoff, not an atomic snapshot. Edits, repository transfers and indexing changes during a run can affect results. A complete total means every search interval was retrieved and reconciled, not an authoritative historical guarantee.
